
# SMART CAMPUS EXCHANGE

### A Marketplace for Buying, Selling, Donating and Exchanging Student Essentials

## 1. Project Overview

Smart Campus Exchange is a verified student marketplace
developed to help college students buy, sell, donate and
exchange essential items within their campus community.

The platform provides a centralized environment where
students can list unused items, request products and
communicate with other verified students.

## 2. Problem Statement

Students often face difficulties in buying and selling
second-hand textbooks, academic materials, hostel items
and other essentials.

Existing communication platforms do not provide a
dedicated and structured campus marketplace.

Smart Campus Exchange addresses this problem through
a centralized and student-verified platform.

## 3. Objectives

- Create a verified student marketplace.
- Encourage reuse and exchange of student essentials.
- Support buying, selling and donating.
- Provide secure student authentication.
- Enable product and request management.
- Provide admin monitoring and complaint management.

## 8. Installation and Setup

### Clone the Repository

git clone https://github.com/SanthiyaShalini/Smart_Campus_Exchange.git

### Backend Setup

1. Open the backend folder.
2. Configure MySQL database credentials.
3. Run the Spring Boot application.

### Frontend Setup

1. Open the frontend folder.
2. Install dependencies using npm install.
3. Start the application using npm run dev.
